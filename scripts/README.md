# Скрипты fliftbot_mapping

- `mapping/` — проверка и постобработка одной записи;
- `evaluation/` — пакетная оценка готовых карт.

Запуск симулятора находится в `../../fliftbot_sim/scripts/`, сбор данных
настоящего робота — в `../../fliftbot_real/scripts/`.

Основная команда:

```bash
./fliftbot_mapping/scripts/mapping/map_build.sh --help
```
