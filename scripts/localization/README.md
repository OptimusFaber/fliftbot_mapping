# Автономная локализация LiDAR без ROS

Скрипты напрямую принимают UDP-пакеты теми же декодерами, что используются для
записи Pandar40P и DePHAN M360. Каждый полный оборот сопоставляется с готовой
Cartographer occupancy-картой (`map.yaml` + `map.pgm`). Результат дописывается
в CSV с четырьмя колонками:

```text
ts,x,y,alpha
```

`ts` — Unix-время приёма последнего пакета оборота; `x`, `y` заданы в метрах в
системе координат карты; `alpha` — курс робота в радианах.

## Запуск

```bash
python3 Pandar_LiDAR/localize.py
python3 DePHAN_LiDAR/localize.py
```

По умолчанию используются уже построенные карты проекта и файлы:

- `ros-data/results/localization/pandar_pose.csv`;
- `ros-data/results/localization/dephan_pose.csv`.

Карту, файл результата и известную примерную начальную позу можно заменить:

```bash
python3 Pandar_LiDAR/localize.py \
  --map /data/map.yaml --out /data/pose.csv --initial 2.5 1.0 0.0
```

Если `--initial` не задан, первый оборот запускает глобальный поиск по всей
карте. В прямоугольных и симметричных помещениях лучше задавать приблизительную
позу: это быстрее и исключает выбор геометрически похожего участка.

Измеренные смещения LiDAR относительно оси поворота применяются автоматически:
Pandar `(0.590, 0.035)`, DePHAN `(1.015, 0.0)` м. Их можно переопределить через
`--sensor-x`, `--sensor-y`, `--sensor-yaw`.

Поза записывается только для качественного совпадения. Пороги регулируются
`--min-overlap` и `--max-rmse`; отклонённые кадры выводятся как `REJECT` и не
портят файл траектории.
