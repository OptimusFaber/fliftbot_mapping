# Examples

`legacy_experiments/` contains historical one-off research scripts. They are
kept for reproducibility, may contain paths from the old `maps/results` layout,
and are not commands for normal simulation operation.

Use `../fliftbot_sim/scripts/` for Gazebo and recording. Use
`scripts/mapping/` here only for offline global-map post-processing.

Small, reproducible examples for simulation and map construction.
